# Levels

| Code | Label | Use |
|------|-------|-----|
| `starter` | Starter | Základ, viac opory, kratšie texty |
| `support` | Support | Bežný školský stred (Zoe / Hugo typ) |
| `advance` | Advance | Rýchlejší temp, menej scaffoldingu |

Každá gramatická téma môže mať až 3 balíčky appiek — nie všetky musia existovať hneď.
