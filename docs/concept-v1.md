# LinguIA — koncept v1

## Problém
Máš veľa HTML edukáčných appiek. Chýba jedna vrstva, ktorá:
- zdiagnostikuje študenta,
- napojí obsah na témy / knihu / unit,
- navrhne online plán, ktorý ty odučíš,
- neskôr sleduje progres (Supabase).

## Riešenie (tenká verzia)
Študent (alebo ty za neho) vyplní onboarding → systém vráti **návrh plánu** (nie finálny automatický kurz).

## Fixná štruktúra hodiny (obsah sa mení)
1. Warm-up / grammar recycle  
2. Listening / input  
3. Controlled practice (gap, T/F, transform…)  
4. Speaking / dialogue  
5. Personal output  
6. Exit ticket / matching  

## Personalizácia (postupne)
1. Téma + level  
2. Kniha / unit (ak je študent viazaný na knihu)  
3. Preferencie a demotivátory (tempo, typ úloh)  
4. Progres (Supabase)  

## Pridaná hodnota
Nie „ďalšia appka“, ale **operátor tvojich materiálov** + diagnostika + plán na odučenie.
